# Shannon Entropy Analysis Pipeline for MSA Data

This document covers standalone use of the entropy scripts:

1. `entropy_msa_og_gene_table.py` - prepare the OG-to-gene mapping table.
2. `msa_to_position_table.py` - convert merged MSA files into a long position table.
3. `calculate_entropy.py` - calculate Shannon entropy per position.
4. `plot_entropy.R` - generate entropy plots.

When using `o2t-step3`, this workflow is run automatically. For integrated Step 3 runs, prefer the `o2t-step3` options documented in the main README, especially `--reference_id`, `--group_by`, `--exclude_gaps`, and `--add_domain`.

## Overview

The entropy workflow processes consensus sequences generated by Read2Tree and calculates position-wise Shannon entropy. It supports amino acid (`AA`) and nucleotide (`DNA`) alignments, optional reference-based coordinates, metadata filtering, grouped entropy calculations, and optional domain annotations in plots.

## Input Files

### MSA Files

- Location: a directory containing merged OG alignments, for example `O2T_RESULTS/06_align_merge_aa/` or `O2T_RESULTS/06_align_merge_dna/`.
- Format: relaxed Phylip as produced by Read2Tree.
- Naming: `OG1.fa`, `OG2.fa`, ..., `OG10.fa`.
- Source: consensus sequences generated by Read2Tree for each ortholog group.

Example:

```text
 1232 634
s0252               ---SPITATV TKTRGIPSAI VCCLTGRDKY PHRGHCYILT SLTKTFMGTV
s0005               ---APITAYS QQTRGLLGCI ITSLTGRDKN QVEGEVQIVS TATQTFLATC
HepC_SRR1170677_1   ---APITAYS QQTRGLLGCI ITSLTGRDKN QVEGEVQVVS TATQSFLATC
```

Reference sample IDs often start with `s0`, and Read2Tree may add `_R1`, `_R2`, `_1`, or `_2` suffixes. The entropy scripts normalize those suffixes when matching metadata labels.

### OG Mapping Table

The position-table script needs a CSV that maps OG IDs to gene names. Step 1 generates the default table at:

```text
stats/entropy/OG_genes_entropy.csv
```

The expected columns are `OG` and either `gene` or `peptide`.

Example:

```csv
OG,gene
OG1,NS3
OG2,NS4A
OG3,NS5B
OG4,NS5A
OG5,E2
```

To generate this table manually from the Step 1 OG table:

```bash
entropy_msa_og_gene_table.py \
  --input stats/References_OGs/OG_genes.tsv \
  --output stats/entropy/OG_genes_entropy.csv
```

Use `--keep_empty_gene` only if you want to retain OGs with empty gene labels.

### Metadata Table

Metadata is optional for standalone entropy, but required for filtering and grouped entropy calculations.

Minimum format:

```csv
label,genotype,collection_year,location
HepC_SRR1170677,GT1,2011,USA
HepC_SRR5122806,GT4,2009,Netherlands
s0252,GT7,2014,Reference
```

For label-aware reference matching, use the Step 3 visualization metadata or provide `--metadata`, `--metadata_match_column`, and `--five_letter`.

## Script 1: Convert MSA to Position Table

Basic amino acid run:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_positions.csv \
  --seq_type AA
```

Basic DNA run:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_dna \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/dna_positions.csv \
  --seq_type DNA
```

Exclude reference sequences:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_positions_no_refs.csv \
  --seq_type AA \
  --exclude_pattern s0
```

Use reference-based coordinates:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_positions.csv \
  --seq_type AA \
  --reference_id s0337
```

Use a metadata label as the reference ID:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_positions.csv \
  --seq_type AA \
  --metadata visualization/omni2treeview_Run.meta.csv \
  --metadata_match_column label \
  --five_letter five_letter_taxon.tsv \
  --reference_id RespiratorysyncytialvirusA
```

Filter by metadata:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_gt1_positions.csv \
  --seq_type AA \
  --metadata metadata.csv \
  --filter_column genotype \
  --filter_value GT1
```

Common options:

```bash
msa_to_position_table.py \
  --msa_dir O2T_RESULTS/06_align_merge_aa \
  --og_table stats/entropy/OG_genes_entropy.csv \
  --output stats/entropy/aa_positions.csv \
  --seq_type AA \
  --reference_id s0337 \
  --metadata metadata.csv \
  --metadata_match_column label \
  --five_letter five_letter_taxon.tsv \
  --filter_column genotype \
  --filter_value GT1 \
  --exclude_pattern s0
```

Position table columns:

- `label` - sample identifier after metadata-aware labeling when metadata is provided.
- `position` - alignment position, 1-indexed.
- `position_alignment` - alignment position when `--reference_id` is used.
- `position_reference` - ungapped reference position when `--reference_id` is used.
- `character` - amino acid or nucleotide at the position.
- `og` - ortholog group, for example `OG1`.
- `gene` - gene or peptide name, for example `NS3`.
- `seq_type` - `AA` or `DNA`.

## Script 2: Calculate Shannon Entropy

Basic run:

```bash
calculate_entropy.py \
  --input stats/entropy/aa_positions.csv \
  --output stats/entropy/aa_entropy.csv
```

Group by one metadata variable:

```bash
calculate_entropy.py \
  --input stats/entropy/aa_positions.csv \
  --output stats/entropy/aa_entropy_by_genotype.csv \
  --metadata metadata.csv \
  --group_by genotype
```

Group by multiple metadata variables:

```bash
calculate_entropy.py \
  --input stats/entropy/aa_positions.csv \
  --output stats/entropy/aa_entropy_by_subgroup_phase.csv \
  --metadata metadata.csv \
  --group_by subgroup time_phase
```

Use reference-based positions generated by `msa_to_position_table.py --reference_id`:

```bash
calculate_entropy.py \
  --input stats/entropy/aa_positions.csv \
  --output stats/entropy/aa_entropy.csv \
  --metadata metadata.csv \
  --use_reference_positions
```

Advanced options:

```bash
calculate_entropy.py \
  --input stats/entropy/aa_positions.csv \
  --output stats/entropy/aa_entropy.csv \
  --metadata metadata.csv \
  --group_by genotype \
  --min_samples 10 \
  --use_reference_positions \
  --exclude_gaps
```

Entropy table columns:

- `gene` - gene or peptide name.
- `og` - ortholog group.
- `position` - alignment position by default, or reference coordinate with `--use_reference_positions`.
- `seq_type` - `AA` or `DNA`.
- `entropy` - Shannon entropy in bits.
- `n_samples` - number of samples at the position.
- `n_unique_chars` - number of unique characters.
- `gap_percent` - percentage of gap characters.
- `most_common_char` - most frequent character.
- Grouping columns, when `--group_by` is provided.

## Script 3: Plot Entropy

Basic plot:

```bash
Rscript plot_entropy.R stats/entropy/aa_entropy.csv stats/entropy
```

With explicit sequence type:

```bash
Rscript plot_entropy.R stats/entropy/aa_entropy.csv stats/entropy AA
```

With domain annotations:

```bash
Rscript plot_entropy.R stats/entropy/aa_entropy.csv stats/entropy AA domains.csv
```

The domain CSV must contain these columns:

```csv
gene,domain,start,end
G,Mucin-like,66,163
G,Central conserved,164,182
G,Hinge,183,237
```

For integrated `o2t-step3` runs, pass the same file with:

```bash
o2t-step3 \
  -o virus2tree_rsv \
  -m data/metadata.csv \
  --seq_type aa \
  --reference_id s0337 \
  --add_domain domains.csv
```

Domain coordinates are interpreted in the entropy coordinate system: alignment positions by default, or reference positions when reference-based coordinates are used.

Plot outputs:

1. `entropy_all_genes.png` - combined faceted plot across genes.
2. `entropy_<gene>.png` - one plot per gene, for example `entropy_NS3.png`.

## Understanding Shannon Entropy

Shannon entropy measures uncertainty or variability at each alignment position.

- `0` bits: all samples have the same character.
- `1` bit: two characters are equally distributed.
- `2` bits: four characters are equally distributed.
- Higher values indicate more variability.

For amino acids, the maximum entropy is approximately `log2(20) = 4.32` bits. For DNA, the maximum entropy is `log2(4) = 2` bits.

## Troubleshooting

### No package called tidyverse

Install the R packages manually:

```bash
Rscript -e "install.packages(c('tidyverse', 'RColorBrewer'), repos='https://cran.rstudio.com/')"
```

### object 'entropy' not found when plotting

This usually means `plot_entropy.R` received the position table instead of the entropy table. Run `calculate_entropy.py` first and pass its output to `plot_entropy.R`.

### No data extracted from MSA files

Check that the MSA files are relaxed Phylip files and that OG names in filenames match the `OG` column in the OG mapping table.

### All samples excluded by filter

Check whether `--exclude_pattern`, `--filter_column`, and `--filter_value` match the labels in the position table or metadata. Run once without filters to inspect available labels.

### Reference positions requested but missing

Run `msa_to_position_table.py` with `--reference_id` first, then run `calculate_entropy.py` with `--use_reference_positions`.
